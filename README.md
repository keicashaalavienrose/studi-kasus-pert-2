# Studi Kasus 2: Simulasi Evakuasi Kendaraan Berbasis High-Performance Computing (HPC)

Proyek ini disusun berdasarkan materi kuliah praktisi High-Performance Computing (HPC) yang disampaikan oleh **Dr. Warawan Diaz Carbalo**.

## Deskripsi Proyek
Proyek ini mengimplementasikan simulasi pergerakan agen atau kendaraan evakuasi di area perkotaan secara iteratif. Menggunakan pemodelan vektor matematika dan pembaruan langkah waktu (*time-step*), skrip ini menghitung arah dan kecepatan evakuasi menuju titik kumpul atau titik aman pusat.

## Pustaka & Teknologi yang Digunakan
- **Python**
- **NumPy** (untuk perhitungan matematis vektor dan langkah waktu)
- **Pandas** (untuk pengelolaan data kerangka agen)
